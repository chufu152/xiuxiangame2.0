# data/ —— 权威数值配置

本目录存放**服务端唯一权威**的游戏数值配置。客户端不持有规则数值，所有"能不能做/产出多少/胜率多少"都由服务端按本配置计算后下发。

## gameConfig.json

- **来源**：1.0 工程 `src/main/resources/gameConfig.json`（1217 行，已在重构需求文档中逐节核对）。
- **迁移任务**：R1 里程碑把 1.0 配置整体复制到本目录后，按下方清单裁剪，并让服务端 `scripts/config/` 加载与校验。
- **格式约定**：保持小驼峰键、枚举大写下划线；不允许在代码里硬编码本该在配置里的数值。

### 保留的配置块（2.0 首版）

| 配置块 | 说明 |
|---|---|
| `map` | 地图宽高、出生点、hex 尺寸、柱高、地形高度、随机种子 |
| `terrain` | 地形类型（平原/险地/森林/山岳/灵脉/灵泉/河流）、移动消耗、产出、防御/高地修正 |
| `disciple` | 境界、岗位、灵根、修炼速度/进度上限、突破概率、心魔、移动力 |
| `faction` | 三流派（宗门/家族/国家）初始资源、特色建筑/兵种、`flavors` 加成 |
| `city` | 建筑、区域、灵峰容量/开峰花费/铺张惩罚、人口、住房、安定、气运、防御、洞府 |
| `improvement` | 建造者次数、改良类型（灵田/梯田/灵矿/采石/药园/聚灵阵/道路/洞府）、修缮 |
| `economy` | 各资源产出、维护、建造/维护成本、道路、威望、奢侈品、声望转化 |
| `dao` | 道统时代、23 条道法（含 4 顿悟）、道点、道法效果（10 类）、核心道法 |
| `explore` | 机缘/秘境成功率、冷却、伤亡、奖励、参与人数、富裕概率 |
| `warfare` | 10 兵种、相克表、9 晋升、战斗系数、地形/城防/经验/撤退、ZOC |
| `policy` | 3 政体、政策卡（**裁剪掉外交类**）、切换冷却、政策效果 |
| `automation` | 自动改良/修缮/道路/探索阈值、自动项目 |
| `vision` | 峰/节点/弟子各境界视野 |
| `victory` | 三流派胜利条件、分数权重、回合上限、覆灭条件 |
| `difficulty` | 3 档难度（AI 倍率/初始资源） |

### 裁剪掉的配置块（2.0 首版不加载，可在文件中保留但标记 `disabled`）

| 配置块 | 处理 |
|---|---|
| `diplomacy`（含 `weariness` 厌战、`relation` 关系、`treaty` 条约、`trade` 交易） | **删除/禁用**。厌战字段、外交状态全部移除 |
| `event`（随机事件库 `library`、路途事件、待决事件） | **删除/禁用**。机缘/秘境节点探索不属于随机事件，保留在 `explore` |
| `disaster`（灵泉枯竭/灵脉震动/天罚雷劫/瘴气，预警/爆发/平息） | **删除/禁用**（归入随机灾害一并暂缓） |
| `threat` / `lair`（蛮族巢穴滋生、强度、清剿） | **删除/禁用** |
| `loyalty` 中导致叛乱/独立的部分（`rebel`、均衡漂移、叛乱结局） | **删除/禁用**。城市基础"安定"保留在 `city` |
| `strategy` / `personalities`（AI 性格、长期战略复盘、外交议程） | **删除/禁用**。保留基础反应式 AI |
| `policy.cards` 中 `category=DIPLOMACY` 的卡（如"远交近攻"） | 删除；世家门阀政体的外交槽位在 `policy.governments` 中改为经济/治理槽 |

> 裁剪后必须通过 `tools/check.ps1` 的配置校验：服务端启动时若仍引用已删模块的字段，应直接报错而非静默。
