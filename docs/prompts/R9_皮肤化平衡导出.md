## 硬约束（违反即返工）

1. **完全 Godot 4.4 + GDScript 静态类型，零 Java**；全仓库无 Java。
2. **换皮肤零代码**：切换皮肤**只允许**改 `assets/manifest.json` 的 `activePack`（或由设置项写入本地偏好后重读 manifest），**不得改任何 `.gd`/`.tscn`**。
3. **资源只经逻辑 ID**：`manifest.json` 是唯一映射；**缺失只 WARN 不崩**（回退占位）；**不得为通过验收而删除回退逻辑**。
4. **相机铁律**：锁 45° 正交、禁旋转；换皮肤、重载资源、导出运行、任何 view 刷新后，`CameraRig` 的 transform 与 `size` 都**不得重置**。
5. **数值平衡只改 `data/gameConfig.json` 数值，不改架构**：**不新增顶层块、不改字段名、不新增命令/错误码/协议字段**；`saveVersion` 保持 "3.0"；`ConfigValidator` 必须仍通过。
6. **确定性不受影响**：平衡微调后，同种子 + 同指令序列**仍逐字一致**（`check.ps1` 双跑 SHA256 断言不得回归）。
7. **导出可独立运行**：导出的 Windows 可执行文件在**无 Godot 编辑器、无源码**的环境下可运行（headless 服务端随客户端自动拉起，端口 9527）。
8. 新增 `class_name` 后必须对两工程分别 `--import`；任何 Agent 跑通后无残留 godot 进程。

## 已裁决冲突（按本提示词执行，禁止自由裁量）

- **裁决一（皮肤切换是「换文件 + 改 `activePack`」，不是代码分支）**：`AssetLibrary` **不得出现 `if pack == "xxx"` 之类的皮肤分支**；所有差异只由 `art/<pack>/` 下的实体文件与 `manifest.json` 决定。
- **裁决二（数值平衡不得改架构）**：R9 只允许改 `data/gameConfig.json` 的**数值**（如难度倍率、造价、胜率参数、产出系数）；**禁止新增/删除/改名键、禁止改 `effects` 类型枚举、禁止改协议形状**。任何平衡改动必须在汇报中**逐条列出旧值→新值**。
- **裁决三（默认皮肤必须自洽完整，不依赖占位回退）**：`activePack=default` 下，`manifest.json` 中**全部逻辑 ID 均有实体文件**，`AssetLibrary` **对任何 ID 都不再 WARN**（R8 只覆盖「最小包」，R9 补全其余）。
- **裁决四（导出不改变运行时行为）**：导出包与编辑器内运行**行为一致**（相机不重置、确定性、69 命令全可用）；**不得为导出而简化玩法或跳过自检**。
- **裁决五（`saves/` 与 `outputs/` 不入库）**：导出与存档目录遵守 `.gitignore`；**不得把导出产物提交进仓库**。
