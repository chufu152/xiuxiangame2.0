1. **完全 Godot 4.4 + GDScript（静态类型），零 Java、零 JVM**：全仓库不得出现 `.java`，不得调用任何外部语言运行时（除 Godot 自身）。

6. 服务端必须能在 `--headless` 下无报错运行；stdout/日志干净，不污染消息帧。

## 要创建的文件（按此清单，不增不减）

### 共享层 `shared/`
- `shared/protocol/commands.gd`：命令名常量（`PING="ping"`，其余里程碑再加；`class_name` 用 `const`）。
- `shared/protocol/msg.gd`：协议常量（`PROTOCOL_VERSION="2.0"`、`SAVE_VERSION="3.0"`、`BACKEND="xiuxian-godot-headless"`、`DEFAULT_PORT=9527`）、消息类型（`HELLO`）、错误码字符串常量（`BAD_JSON/NO_ID/BAD_REQUEST/UNKNOWN_COMMAND/NOT_IMPLEMENTED/BAD_PARAMS/NO_GAME/INTERNAL`）。
- `shared/protocol/enums.gd`：占位（R0 留空框架并加注释，后续里程碑填枚举）。
- `shared/protocol/dto.gd`：静态类型的信封解析/构造辅助函数（解析一条文本帧为 Dictionary；构造 `ok`/错误响应；**不解析未知字段、不做玩法**）。
- `shared/geo/hex.gd`：仅放 `const` 占位与注释（轴向/世界坐标 R1 实现），R0 不要写地图逻辑。

### 服务端 `server/`
- `server/project.godot`：Godot 4.4 项目；主场景 `res://scenes/ServerMain.tscn`；配置窗口不影响 headless；应用名 xiuxian-server。
- `server/scenes/ServerMain.tscn` + `server/scenes/ServerMain.gd`：根 Node，`_process` 驱动网络循环；启动时打印一行 `server listening on 127.0.0.1:9527`（stderr/print 均可，WebSocket 帧另走）。
- `server/scripts/net/NetServer.gd`：
  - 用 `TCPServer.listen(9527, "127.0.0.1")`；每帧 `is_connection_available()` 时 `take_connection()`，为每个连接 `WebSocketPeer.new()` 并 `accept_stream(stream)`。
  - 维护连接列表，每帧对每个 peer `poll()`、按 `get_ready_state()` 处理 OPEN/CLOSED；用 `get_packet_count()`/`get_packet()` 取文本帧（UTF-8 解码）。
  - 新连接 OPEN 后**第一条**主动发 `hello`。
  - 用 `send_text()` 发送紧凑 JSON（帧内不得出现裸换行）。
- `server/scripts/net/CommandDispatcher.gd`：
  - 分发：`ping` → `{"id":<回显>,"ok":true,"result":{"pong":true}}`（不带 view）。
  - 错误码框架：非合法 JSON→`BAD_JSON`；缺 `id`→`NO_ID`；缺/非字符串 `type`→`BAD_REQUEST`；未登记命令→`UNKNOWN_COMMAND`（`id` 能回显就回显）。
  - 顺序处理（R0 单连接也按顺序响应）。
- `server/scripts/config/ConfigLoader.gd` + `ConfigValidator.gd`：
  - 定位并读取 `data/gameConfig.json`（相对仓库根；用传入的 `--data` 路径或默认 `res://../data/` 解析）。R1 才放全量，**R0 允许读一个最小占位文件**（见下）。
  - 读不到/JSON 非法 → 明确报错并退出（非零码），不许静默。
- `data/gameConfig.json`（R0 最小占位，顶层）：仅 `{ "schemaVersion": "3.0", "meta": { "note": "R0 placeholder, full config migrated in R1" } }`。
- `server/tests/SmokeTest.tscn` + `server/tests/SmokeTest.gd`：headless 自测客户端（见验收）。

### 客户端 `client/`
- `client/project.godot`：Godot 4.4；主场景 `res://scenes/Main.tscn`；应用名 xiuxian-client。
- `client/scenes/Main.tscn` + `client/scenes/Main.gd`：界面显示「连接状态」「hello 各字段」「一个 Ping 按钮」「回包日志」；启动自动连接。
- `client/scripts/net/NetClient.gd`：
  - `WebSocketPeer.new()` + `connect_to_url("ws://127.0.0.1:9527")`；每帧 `poll()`；连接建立后等待 `hello`，解析后发信号给 UI。
  - 提供 `send_command(type, params)`；按 `id` 匹配响应；UI 点 Ping 发 `{"id":"c1","type":"ping"}` 并展示回包。
  - 首连失败自动重试若干次（指数退避，上限后提示），R0 不做复杂断线重连。
- `client/scripts/net/Launcher.gd`：
  - 若 9527 连不上，按顺序找 Godot 可执行（环境变量 `GODOT_CONSOLE_EXE` → `tools/godot_path.txt`（不入库）→ 固定路径 `C:\Users\Administrator\godot\Godot_v4.4.1-stable_win64_console.exe`），用 `OS.create_process(...)` 以 `--headless --path <abs server>` 拉起服务端，记录 PID。
  - 客户端退出时 `OS.kill(pid)` 关闭自己拉起的子进程。

## 握手与消息契约（严格按 §6）

服务端首帧（连接建立即发）：
```json
{"type":"hello","protocolVersion":"2.0","backend":"xiuxian-godot-headless","saveVersion":"3.0","implementedCommands":["ping"]}
```
请求：
```json
{"id":"c1","type":"ping"}
```
成功响应：
```json
{"id":"c1","ok":true,"result":{"pong":true}}
```
失败响应：
```json
{"id":"c1","ok":false,"errorCode":"UNKNOWN_COMMAND","message":"..."}
```

## 自动验收（`tools/check.ps1`，必须全部通过）

`check.ps1` 自动完成：
1. 运行 `setup_shared.ps1`，断言 `client/shared` 与 `server/shared` 均指向顶层 `shared`（在其中建临时文件，另一处可见；测试后删除）。
2. 用 console 版 `--headless --path server` 启动服务端。
3. 用 console 版 `--headless --path server res://tests/SmokeTest.tscn` 跑无头自测，它必须：
   - 连上 `ws://127.0.0.1:9527`，收到 `hello`，断言 `protocolVersion=="2.0"`、`saveVersion=="3.0"`、`implementedCommands` 含 `ping`；
   - 发 `ping`，断言回包 `ok==true`、`id` 回显、`result.pong==true`；
   - 发一个未登记命令，断言 `ok==false` 且 `errorCode=="UNKNOWN_COMMAND"`；
   - 发缺 `id` 的帧，断言 `errorCode=="NO_ID"`；
   - 全部通过打印 `SMOKE_PASS` 并以退出码 0 结束，否则 `SMOKE_FAIL` 退出码 1。
4. check.ps1 捕获测试结果后，**清理所有由本脚本/客户端启动的 Godot 进程**（按 PID 或匹配命令行），最终 `tasklist` 不残留本次拉起的 godot。
5. 扫描仓库确认无 `.java` 文件。
6. 你还需手动（或在 GUI 版验证）：打开客户端能显示「已连接」与 hello 字段，点 Ping 按钮有回包；关闭客户端后服务端子进程被回收（Launcher 路径）。
