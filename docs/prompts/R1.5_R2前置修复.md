## 任务 A：挂载本 worktree 并恢复导入缓存（最先做，约 5 分钟）

> 根因：`client/shared`、`server/shared` 是目录联接（junction），**不入库、不随 worktree 自动创建**；每个新 worktree 都要挂一次。`tools/setup_shared.ps1` 用脚本所在目录的**相对路径**定位 `shared`，在任何 worktree 里都指向**该 worktree 自己的** `shared/`，可安全重复执行。

在你的 worktree 根目录（PowerShell）：

```powershell
# 1) 挂载 shared 联接（幂等，会先移除旧联接再建）
powershell -ExecutionPolicy Bypass -File tools\setup_shared.ps1

# 2) 自检：内含两工程 --import（生成 .godot/global_script_class_cache.cfg）、junction 断言、
#    配置负向、headless 监听、SmokeTest/R1Test、无残留进程、零 .java 扫描
powershell -ExecutionPolicy Bypass -File tools\check.ps1
```

**验收（A）**：
- `client/shared`、`server/shared` 均为 junction（`Get-Item -Force` 的 `LinkType=Junction`），目标是**本 worktree 内**的 `shared/`，不是主仓库路径；
- 在 `client/shared` 下新建一个临时文件，能在 `server/shared` 与本 worktree 顶层 `shared/` 看到，随后删除（双向可见）；
- `check.ps1` 输出 `CHECK_RESULT=OK`，**R0、R1 全部断言保持绿**（含 R1 的固定种子双跑、地形/河流比例、视野），不得因挂载导致 R1 回归；
- 无残留 godot 进程。

> 若 `check.ps1` 报 `class_name not declared`，确认是否已对两个工程分别执行 `--headless --path client --import`、`--headless --path server --import`（check 已内置，单独调试时手动补）。

### B.2 每条命令的固定条目（格式统一）

对 §2–§9 中**每一条**命令，给出：

- **用途**：一句话；
- **params**：表格 `字段 | 类型 | 必填 | 默认/缺省 | 含义 | 出处`；
- **result**：成功业务返回字段（`ok:true` 信封内的 `result` 结构），逐字段；
- **view**：是否随响应回 `view`（只读 `query*` 不回 view）；
- **events**：会产生哪些事件（若 1.0 有）；
- **errorCode**：可能返回的错误码（`BAD_PARAMS`/`NO_GAME`/…，沿用 `msg.gd` 既有码表，**不新增码**）；
- **里程碑**：R2–R9 中的归属；
- **状态**：`已实现`（ping/newGame/getState）或 `待实现（R*）`；
- **出处**：1.0 文件名+章节，或 2.0 代码文件。
