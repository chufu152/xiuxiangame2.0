# 前端美术风格参考（权威美术依据）

> 来源：用户提供的《前端美术设计参考》。本文件是 2.0 客户端美术与地图表现的**权威依据**，`docs/REQUIREMENTS_2.0.md` 第 3 章、4.1.10、4.2、8.4 的美术要求均以本文件为准。**最终定位为简化手绘水墨风 2.5D：使用 3D 低模资产，但锁定正交 45° 等距相机、不可旋转，不做自由 3D 视角（正文中的"3D 模型/实景"均指 2.5D 固定等距下的模型与实景）。**

## 一、整体美术风格

1. **风格定位**：简化手绘水墨 3D，造型轮廓清晰。俯瞰全局时一眼识别地形、建筑、资源；拉近镜头能看到模型细节与动态小效果（飞鸟、风吹草木）。
2. **色彩语言**：用固定色彩区分功能（如炼丹房红色=丹道、药田绿色=种植）；不同地形（草原/平原/沙漠/冻土）有专属底色，便于快速读图。
3. **山水画骨架**：以青绿山水、水墨山水为基底；远景云雾缭绕、层峦叠嶂，不精细刻画山石纹理，重在营造缥缈深远的空间感；大量留白与云雾分割空间，营造仙境虚无感。

## 二、地图建模与三层迷雾（画卷核心机制）

- 地图全部基于**六边形地块**；山脉可跨多格形成连绵山体（山脊结点）；地形高度分层、有简单高低起伏，不是纯平面。
- 地块 3 种视觉状态：
  1. **未探索 Fog of War —— 宣纸空白画卷**：整块为米白色宣纸纹理，无任何地形细节，完全隐藏地貌与资源；单位探索到边缘时，宣纸像**泼墨一样"褪去"**，露出下方实景。
  2. **已探索无视野 Mid-fog —— 记忆手绘地图**：保留曾发现的地形轮廓，变为**水墨画古地图**（排线、速写线条绘制山脉/森林/河流/改良/城市）；可见固定地形、城市、改良；**不显示单位**，也**不记录失去视野后敌方新造的建筑/改良**（如同手绘地图留存）。
  3. **当前视野 Visible —— 实时 3D 实景**：完整 3D 地块 mesh、植被、资源模型、单位、城市、全部改良、动态光影。

## 三、地块开发后的建模变化

1. **基础地形原生模型**：草原/平原=草地+零星树木；丘陵=抬升地形+岩石；山脉=不可通行高大山体；森林/雨林=成片树木模型。
2. **改良设施（Tile Improvement）**：在地块上叠加独立小型模型（开垦农田=梯田、矿场=矿井脚手架、采石场、种植园、营地等）；建造后模型直接叠加；**被掠夺后模型破损、破败**。
3. **区域/城区（District）**：建筑不再全部堆叠单格；每个城区占独立六边形，生成整套建筑群模型（宫殿、庙宇、广场等），附带配套道路与装饰。
4. **道路系统**：地块之间自动生成道路，青石砖。

## 四、UI 与地图表现细节

1. 六边形网格线可开关；地块归属用**宗门颜色边框**标识。
2. 简易昼夜循环；草木轻微摆动；建筑粒子特效；**所有模型做轮廓强化**，缩小到全局视角时仍能分辨设施、不糊成一团（可读性优先）。

## 五、意象、建筑、符号与视觉语言

- **意象**：祥云、仙鹤、灵松、灵泉、玉阶、丹炉、灵植、灵脉。
- **建筑**：斗拱飞檐、悬楼、洞府、天宫琼楼；依山而建、半嵌山体，建筑融于山水，不破坏自然。
- **符号**：符文、法阵、八卦、云纹、卷草纹；发光特效多用金色、青蓝色。
- **人物服饰**：仙袍薄纱、广袖、多层飘带，动态随风飘动；纹样云纹、水纹、缠枝莲；低阶粗布锦缎，高阶玉质流光纱。
- **法器灵物**：剑、玉如意、莲台、丹炉、灵灯；造型优雅、少粗重铁器；高阶法器自带持续微光、符文流转。
- **灵气特效**：流动云气、粒子光效、法阵光晕；仙侠是灵气流、云纹、符文（如水流转），区别于西方魔法的火焰雷电几何法阵。
- **主色**：青、白、浅金；材质为白玉、玉石、云；云雾厚重、浮空山体、流水为灵泉；建筑轻盈高挑、飞檐舒展、多平台露台、少厚重墙体；整体干净明亮、灵气粒子漂浮。
